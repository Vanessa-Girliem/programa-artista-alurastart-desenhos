<h1>🖌️ Desenhos Pixelados</h1>

  <p></p>
  <p>Este projeto foi desenvolvido na orientação da plataforma educacional <strong>Alura Start</strong>.</p>
  <p>Através desse projeto simples, é possível realizar desenhos semelhantes ao estilo <strong>Pixel Art</strong>. Pressionando o mouse no espaço em branco e traçando um desenho, é possível desenhar qualquer coisa.</p>

<code>→ Como executar o projeto?</code>
<p></p>
<ul>
  <li>Clique no botão de "Play";</li>
  <li>Pressione o espaço em branco com o mouse, e trace um rascunho;</li>
  <li>Para reiniciar o desenho, basta clicar no no botão "Stop", e dessa maneira você poderá refazer ou começar um novo desenho.</li>
</ul>
